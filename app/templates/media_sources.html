SMB-Medienquellen

Hier verwaltest du, welcher SMB-Pfad hinter einem Ordneralias steckt. Jede Quelle kann danach in der Bibliothek einer Playlist und einem oder mehreren Pis zugeordnet werden.

Sicherheit: Das UI speichert ausschließlich Pfade, keine SMB-Passwörter. Der separate Host-Mountdienst darf nur vorher von IT freigegebene Server/Freigaben verwenden und mountet schreibgeschützt. Eine geänderte aktive Freigabe wird niemals automatisch ausgehängt.
